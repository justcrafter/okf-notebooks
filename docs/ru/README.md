## Основная модель

- **Блокнот** — каталог `notebooks/<slug>/` с заметками в Markdown и метаданными `.okf/notebook.yaml`.
- **Тип** — вид заметки (`Decision`, `Playbook`…). Каждому типу соответствует подкаталог, набор полей frontmatter,
  обязательные поля и срок устаревания `stale_after`.
- **Пресет** — готовый набор типов, из которого блокнот берёт словарь при создании.
- **Актор** — кто пишет: `claude-code`, `opencode`, `external-harness` (по токену) или `human` (только CLI и веб-интерфейс ревью).
  Личность и права определяются только токеном, агент их не выбирает.
- **Политика создания** (`off` / `proposal` / `direct`) — может ли агент заводить блокноты и типы сам.
