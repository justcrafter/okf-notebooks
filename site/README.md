# okf-notebooks site

Source of [okf-notebooks.kazakov.dev](https://okf-notebooks.kazakov.dev/): the landing page, install guide,
scenarios and documentation, in English (`content/en`) and Russian (`content/ru`). Built with Hugo and its own
templates (no theme).

```text
content/{en,ru}/_index.md     landing page (all copy lives in its front matter)
content/{en,ru}/install.md    install, connecting agents, configuration, CLI
content/{en,ru}/scenarios.md  usage scenarios
content/{en,ru}/docs/         reference pages, ordered by `weight`
layouts/                      templates; _markup/render-link.html resolves `.md` links
assets/css/                   styles; syntax.css is generated by `hugo gen chromastyles`
static/images/                screenshots, also used by the root README
```

## Writing content

- Change `content/en` and `content/ru` together.
- Link to other pages by their source path: `[presets](/docs/presets.md)`, `[install](/install.md#with-docker)`.
  The link hook turns it into the URL of the page in the same language, and the build fails on a broken link.
- Link to repository files with full GitHub URLs.

## Run locally

```bash
hugo server -s site
```

## Image

```bash
docker build -t okf-notebooks-site site
docker run --rm -p 127.0.0.1:8080:8080 okf-notebooks-site
```

nginx serves the static files on port 8080 (`/healthz` for probes). TLS is terminated by the reverse proxy in front
of it. CI publishes `ghcr.io/justcrafter/okf-notebooks-site:latest` and `:sha-<short>` on every push to `main` that
touches `site/`.
